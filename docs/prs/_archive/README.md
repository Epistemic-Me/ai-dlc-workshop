# Archived PRs

Ten example merged PRs, each with its five docs, for the Lab 3 labeling step. They describe features that are in this repo, but they are teaching examples written for the lab: the git history of this repo does not contain them.

Label each PR `good` or `bad` against `docs/SPEC-CHECKLIST.md`, and tag its domain. Compare labels with another pair.

New PRs land here when they merge: `/review-pr` ends with a person merging, and then the folder moves from `docs/prs/implementing/` to `docs/prs/_archive/`.

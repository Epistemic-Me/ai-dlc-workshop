# /plan-pr <TICKET>

Type the ticket ID after the command.

Read the ticket, `RESEARCH.md`, the related spec, and `docs/SPEC-CHECKLIST.md`. Fill `TEST-STRATEGY.md` with one test and expected evidence for every acceptance criterion. Fill `IMPLEMENTATION-PLAN.md` with scoped steps, files, risks, and rollback. Do not change app code. Report any criterion that cannot be tested.
